# Поиск экстремума: Производная vs Алгебра

> [!abstract] Главный принцип
> Производная — универсальный, но «тяжёлый» инструмент. Если функцию можно свести к базовым свойствам (вершина параболы, изоляция переменной, монотонность, неравенство Коши), алгебраический способ экономит время и страхует от громоздкого дифференцирования сложных дробей и корней.

---

## Экспресс-фильтр выбора метода

```
[Анализ функции f(x)]
          │
          ▼
1. Числитель дроби можно сделать числом (константой)?
   ├── ДА  ──► max(C / g(x)) ⟷ min g(x). Дробь сводится к знаменателю.
   └── НЕТ ──► Шаг 2.
          │
          ▼
2. Переменная входит как чётные степени или одинаковый блок (2ˣ, ln x)?
   ├── ДА  ──► Замена u = g(x) ──► Парабола au² + bu + c. Вершина: u₀ = -b / (2a).
   └── НЕТ ──► Шаг 3.
          │
          ▼
3. Получается сумма вида t + C/t (где t > 0, C > 0)?
   ├── ДА  ──► Неравенство Коши: min при t = √C.
   └── НЕТ ──► Шаг 4.
          │
          ▼
4. Переменная «размазана» по разным функциям (x · eˣ, x · ln x) или степень ≥ 3?
   └── ДА  ──► Только производная: f'(x) = 0.
```

---

## Четыре обходных алгебраических приёма

### 1. Изоляция переменной в знаменателе
Если степени числителя и знаменателя совпадают, делим числитель и знаменатель на переменную:
$$\max \frac{k \cdot \tau^2}{\sqrt{f(\tau)}} = \max \frac{k}{\sqrt{\dfrac{f(\tau)}{\tau^4}}} \iff \min \frac{f(\tau)}{\tau^4}$$

> [!tip] Правило переворота
> При положительном числителе $C > 0$:
> * $\max \dfrac{C}{g(x)} \iff \min g(x)$
> * $\min \dfrac{C}{g(x)} \iff \max g(x)$

### 2. Скрытая квадратичная функция (парабола)
Если после преобразования или деления получается выражение от одной и той же структуры:
* $f(x) = A \cdot (g(x))^2 + B \cdot g(x) + C$
* Замена: $u = g(x)$
* Экстремум квадратичной функции $y = Au^2 + Bu + C$ находится без производной через абсциссу вершины:
  $$u_0 = -\frac{B}{2A}$$
* При $A > 0$ в вершине достигается **минимум**, при $A < 0$ — **максимум**.

### 3. Конструкция Коши (сумма взаимно обратных)
Для любых положительных величин $a > 0, b > 0$:
$$\frac{a + b}{2} \ge \sqrt{ab} \implies a + b \ge 2\sqrt{ab}$$
Равенство (наименьшее значение суммы) достигается тогда и только тогда, когда $a = b$.

**Шаблон:**
$$g(t) = t + \frac{C}{t} \implies \min \text{ при } t = \frac{C}{t} \implies t^2 = C \implies t = \sqrt{C}$$

### 4. Внешняя монотонная оболочка
Функции $y = \sqrt{t}$, $y = \ln t$, $y = a^t$ (при $a > 1$) **строго монотонно возрастают** на всей своей области определения:
$$\operatorname{ext} \sqrt{g(x)} \quad \text{достигается в той же точке } x, \text{ что и} \quad \operatorname{ext} g(x)$$
Внешний корень или логарифм можно отбросить при поиске точки экстремума (но вернуть при подсчёте самого значения функции).

## Когда производная СТРОГО ОБЯЗАТЕЛЬНА

> [!danger] Маркеры обязательного перехода к производной:
> 1. **Смешение функциональных классов («разные миры»):**
>    * Многочлен $\times$ Экспонента: $(x^2 - 3x + 3)e^{x-2}$
>    * Многочлен $\times$ Тригонометрия: $(x - 2)\cos x + \sin x$
>    * Алгебра + Логарифм: $x^2 - 8x + 12\ln x$
> 2. **Многочлены третьей степени и выше:**
>    * $f(x) = x^3 - 6x^2 + 9x + 15$ (нет симметрии параболы).
> 3. **Несимметричные дробно-рациональные функции без возможности деления:**
>    * $\dfrac{x^2 + 25}{x}$ — решается через Коши ($x + \frac{25}{x}$), но $\dfrac{x^2 - 4x + 25}{x - 1}$ надёжнее дифференцировать.

---

> [!example] Разбор примера из Задания 17 (Лайнер на волнах)

**Функция:**
$$A(\tau) = k\theta_0 \frac{\tau^2}{\sqrt{(T^2 - \tau^2)^2 + n\tau^2 T^2}}$$

1. **Изоляция:** делим подкоренное выражение на $(\tau^2)^2 = \tau^4$:
   $$A(\tau) = \frac{k\theta_0}{\sqrt{\left(\dfrac{T^2}{\tau^2} - 1\right)^2 + n\dfrac{T^2}{\tau^2}}}$$
2. **Замена:** пусть $u = \dfrac{T^2}{\tau^2}$ ($u > 0$):
   $$f(u) = (u - 1)^2 + nu = u^2 + (n - 2)u + 1$$
3. **Вершина параболы (без производной):**
   $$u_{\min} = -\frac{n - 2}{2 \cdot 1} = 1 - \frac{n}{2}$$
4. **Возврат к переменной:**
   $$\frac{T^2}{\tau^2} = 1 - \frac{n}{2} \implies \tau = \frac{T}{\sqrt{1 - 0{,}5n}}$$
