# Метод рационализации (метод декомпозиции)
> [!abstract] Суть метода
> Метод рационализации позволяет заменить сложный знакопеременный множитель (логарифмический, показательный, иррациональный или модуль) на более простой алгебраический множитель, имеющий **в точности такой же знак** на области допустимых значений (ОДЗ).

---

> [!danger] Главные условия применимости
> 1. Неравенство **обязано** быть приведено к сравнению с нулём:
>    $$\frac{A_1 \cdot A_2 \cdots A_k}{B_1 \cdot B_2 \cdots B_m} \lor 0, \quad \text{где } \lor \in \{>, <, \ge, \le\}$$
> 2. Заменять можно **только множители** (в произведении или дроби). Заменять отдельные слагаемые внутри сумм категорически запрещено.
> 3. Все переходы равносильны **исключительно на ОДЗ** исходного неравенства.

---

## Сводная таблица замен

| **Исходный множитель**              | **Знак совпадает со знаком** | **Ограничения (ОДЗ)**                                    |
| ----------------------------------- | ---------------------------- | -------------------------------------------------------- |
| $\log_a f - \log_a g$               | $(a - 1)(f - g)$             | $a > 0, \; a \neq 1, \; f > 0, \; g > 0$                 |
| $\log_a f$                          | $(a - 1)(f - 1)$             | $a > 0, \; a \neq 1, \; f > 0$                           |
| $a^f - a^g$                         | $(a - 1)(f - g)$             | $a > 0$ (если $a > 1$, множитель $(a-1) > 0$ опускается) |
| $a^f - 1$                           | $(a - 1)f$                   | $a > 0$                                                  |
| $\sqrt{f} - \sqrt{g}$               | $f - g$                      | $f \ge 0, \; g \ge 0$                                    |
| $\sqrt{f} - g$                      | $f - g^2$                    | $f \ge 0, \; g \ge 0$                                    |
| $\vert{}f\vert{} - \vert{}g\vert{}$ | $(f - g)(f + g)$             | Ограничений нет                                          |

## Алгоритм решения в бланке № 2

```
[Исходное неравенство]
          │
          ▼
   1. Найти ОДЗ
          │
          ▼
   2. Перенести всё влево, разложить на множители: F(x) / G(x) ∨ 0
          │
          ▼
   3. Написать обоснование: «На ОДЗ знаки множителей совпадают...»
          │
          ▼
   4. Заменить множители по таблице и решить методом интервалов
          │
          ▼
   5. Наложить ОДЗ на найденные промежутки -> Записать ответ
```

> [!example] Эталонное оформление задачи из ЕГЭ (вариант 1 под редакцией Ященко)

**Неравенство:**
$$\frac{2^{2x+1} + x - 5\sqrt{x} - 12}{4^x - 8} \ge 2$$

**1. ОДЗ:**
$$\begin{cases} x \ge 0 \\ 4^x - 8 \neq 0 \end{cases} \iff \begin{cases} x \ge 0 \\ x \neq 1{,}5 \end{cases} \iff x \in [0; 1{,}5) \cup (1{,}5; +\infty)$$

**2. Приведение к каноническому виду:**
$$\frac{2 \cdot 4^x + x - 5\sqrt{x} - 12 - 2(4^x - 8)}{4^x - 8} \ge 0$$
$$\frac{x - 5\sqrt{x} + 4}{4^x - 8} \ge 0 \iff \frac{(\sqrt{x} - 1)(\sqrt{x} - 4)}{2^{2x} - 2^3} \ge 0$$

**3. Применение метода рационализации:**
На ОДЗ знаки множителей совпадают со знаками соответствующих алгебраических выражений:
* $\sqrt{x} - 1 = \sqrt{x} - \sqrt{1} \;\longrightarrow\; x - 1$
* $\sqrt{x} - 4 = \sqrt{x} - \sqrt{16} \;\longrightarrow\; x - 16$
* $2^{2x} - 2^3 \;\longrightarrow\; (2 - 1)(2x - 3) = 2x - 3$

**4. Решение рационального неравенства:**
$$\frac{(x - 1)(x - 16)}{2x - 3} \ge 0$$
Нули: $x = 1$ (закрашенная), $x = 16$ (закрашенная), $x = 1{,}5$ (выколотая).

Методом интервалов получаем:
$$x \in [1; 1{,}5) \cup [16; +\infty)$$

**5. Пересечение с ОДЗ:**
Найденное множество целиком лежит в полуинтервале $[0; 1{,}5) \cup (1{,}5; +\infty)$, поэтому дополнительных отсечений нет.

**Ответ:** $[1; 1{,}5) \cup [16; +\infty)$
