## Физический (механический) смысл производной
Пусть закон прямолинейного движения материальной точки задан функцией координаты от времени: $x(t)$ (или $s(t)$).

- Мгновенная скорость — первая производная пути по времени:
- ### $v(t) = x'(t)$
- Мгновенное ускорение — производная скорости (вторая производная пути):
- ### $a(t) = v'(t) = x''(t)$
- Условие остановки материальной точки:
- ### $v(t) = 0 \iff x'(t) = 0$

## Геометрический смысл производной
Значение производной функции $y = f(x)$ в точке $x_0$ равно угловому коэффициенту касательной $k$, проведённой к графику функции в точке $(x_0; f(x_0))$, и равно тангенсу угла наклона $\alpha$ этой касательной к положительному направлению оси $Ox$:

- ### $f'(x_0) = k = \operatorname{tg} \alpha$

### Знак и значение производной по углу касательной:
- $\alpha$ — острый угол ($0^\circ < \alpha < 90^\circ$):
- ### $k > 0 \implies f'(x_0) > 0$
- $\alpha$ — тупой угол ($90^\circ < \alpha < 180^\circ$):
- ### $k < 0 \implies f'(x_0) < 0$
- Касательная горизонтальна ($\alpha = 0^\circ$):
- ### $k = 0 \implies f'(x_0) = 0$

### Уравнение касательной и параллельность
- Уравнение касательной в точке $x_0$:
- ### $y = f(x_0) + f'(x_0)(x - x_0)$
- Условие параллельности касательной прямой $y = kx + b$:
- ### $f'(x_0) = k$

## Связь свойств функции $f(x)$ и её производной $f'(x)$

| Свойство функции $y = f(x)$ | Поведение производной $y = f'(x)$ |
| :--- | :--- |
| Функция **возрастает** на интервале | $f'(x) \ge 0$ (на промежутках) |
| Функция **убывает** на интервале | $f'(x) \le 0$ (на промежутках) |
| **Точка экстремума** (максимум или минимум) | $f'(x) = 0$ (производная меняет знак) |
| **Точка максимума** ($x_{\max}$) | $f'(x)$ меняет знак с **$+$ на $-$** |
| **Точка минимума** ($x_{\min}$) | $f'(x)$ меняет знак с **$-$ на $+$** |
| Функция постоянна ($f(x) = \text{const}$) | $f'(x) = 0$ |

## Разбор двух типов графиков в задании ЕГЭ

> [!important] Главное правило чтения задачи
> Перед началом решения всегда проверять, чей график изображён: **самой функции** $y = f(x)$ или **её производной** $y = f'(x)$.

### Сценарий 1: Дан график функции $y = f(x)$
- **Промежутки возрастания/убывания:** смотрим, где линия графика визуально идёт вверх ($f'(x) > 0$) или вниз ($f'(x) < 0$).
- **Точки экстремума:** это координаты $x$ вершин «вершин-горок» ($x_{\max}$) и «ям-впадин» ($x_{\min}$). В них касательная горизонтальна ($f'(x) = 0$).
- **Поиск значения $f'(x_0)$ по касательной:**
	1. Найти две целочисленные точки на касательной сетки.
	2. Построить прямоугольный треугольник: $k = \pm \frac{\Delta y}{\Delta x}$ ($+$ если прямая возрастает, $-$ если убывает).

---

### Сценарий 2: Дан график производной $y = f'(x)$
Внимание фокусируется только на **знаке значений** (выше/ниже оси $Ox$) и **нулях функции** (пересечениях с осью $Ox$):
- **Функция $f(x)$ возрастает:** там, где график $f'(x)$ лежит **выше оси $Ox$** ($y > 0$).
- **Функция $f(x)$ убывает:** там, где график $f'(x)$ лежит **ниже оси $Ox$** ($y < 0$).
- **Точки экстремума функции $f(x)$:** точки **пересечения** графика с осью $Ox$ ($y = 0$).
	- $x_{\max}$: график $f'(x)$ переходит из верхней полуплоскости в нижнюю (знак меняется с $+$ на $-$).
	- $x_{\min}$: график $f'(x)$ переходит из нижней полуплоскости в верхнюю (знак меняется с $-$ на $+$).
- **Наибольшее/наименьшее значение $f(x)$ на отрезке $[a; b]$:**
	- Если на отрезке $f'(x) \ge 0$, то $f(x)$ монотонно растёт $\implies \max = f(b), \, \min = f(a)$.
	- Если на отрезке $f'(x) \le 0$, то $f(x)$ монотонно убывает $\implies \max = f(a), \, \min = f(b)$.

## Первообразная (связь $F(x)$ и $f(x)$)
- Функция $F(x)$ называется первообразной для $f(x)$, если:
- ### $F'(x) = f(x)$
*(Свойства графика $F(x)$ соотносятся с $f(x)$ точно так же, как свойства $f(x)$ с $f'(x)$).*

- **Геометрический смысл интеграла (площадь криволинейной трапеции):**
- ### $S = F(b) - F(a)$
	- $a, b$ — левая и правая границы фигуры по оси $Ox$.
