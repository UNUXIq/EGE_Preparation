## Формулы сокращённого умножения (ФСУ)
- Разность квадратов:
- ### $a^2 - b^2 = (a - b)(a + b)$
- Квадрат суммы и разности:
- ### $(a \pm b)^2 = a^2 \pm 2ab + b^2$
- Сумма и разность кубов:
- ### $a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$
- Куб суммы и разности:
- ### $(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$

## Свойства степеней и корней ($a > 0, \, b > 0$)
- ### $a^x \cdot a^y = a^{x + y}, \quad \frac{a^x}{a^y} = a^{x - y}, \quad (a^x)^y = a^{xy}$
- ### $(ab)^x = a^x b^x, \quad \left(\frac{a}{b}\right)^x = \frac{a^x}{b^x}$
- ### $a^{-x} = \frac{1}{a^x}, \quad a^0 = 1, \quad a^{\frac{m}{n}} = \sqrt[n]{a^m}$
- Арифметический квадратный корень:
- ### $\sqrt{a^2} = |a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}$
- ### $\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}, \quad \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$

## Свойства логарифмов ($a > 0, \, a \neq 1, \, b > 0, \, c > 0$)
- Базовые соотношения:
- ### $\log_a 1 = 0$
- ### $\log_a a = 1$
- ### $\log_a \frac{1}{a} = -1$
- ### $\log_{a^k} a = \frac{1}{k}$
- ### $\log_a a^m = m$
- Основное логарифмическое тождество:
- ### $a^{\log_a b} = b$
- Произведение и частное:
- ### $\log_a (bc) = \log_a b + \log_a c$
- ### $\log_a\left(\frac{b}{c}\right) = \log_a b - \log_a c$
- Вынос показателей степеней:
- ### $\log_{a^m} (b^k) = \frac{k}{m} \log_a b$
- ### $\log_a (b^{2k}) = 2k \log_a |b|$
- Переход к новому основанию:
- ### $\log_a b = \frac{\log_c b}{\log_c a}, \quad \log_a b = \frac{1}{\log_b a}, \quad a^{\log_c b} = b^{\log_c a}$

## Квадратные уравнения ($ax^2 + bx + c = 0, \, a \neq 0$)
- Дискриминант:
- ### $D = b^2 - 4ac \implies x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$
- Чётный второй коэффициент ($b = 2k$):
- ### $D_1 = k^2 - ac \implies x_{1,2} = \frac{-k \pm \sqrt{D_1}}{a}$
- Теорема Виета:
- ### $\begin{cases} x_1 + x_2 = -\frac{b}{a} \\ x_1 \cdot x_2 = \frac{c}{a} \end{cases}$
- Разложение на множители:
- ### $ax^2 + bx + c = a(x - x_1)(x - x_2)$

## Методы сведения уравнений к простейшим

### 1. Дробно-рациональные уравнения
- ### $\frac{f(x)}{g(x)} = 0 \iff \begin{cases} f(x) = 0 \\ g(x) \neq 0 \end{cases}$

---

### 2. Иррациональные уравнения
- Корень чётной степени (равносильный переход):
- ### $\sqrt{f(x)} = g(x) \iff \begin{cases} f(x) = g^2(x) \\ g(x) \ge 0 \end{cases}$
- Два корня:
- ### $\sqrt{f(x)} = \sqrt{g(x)} \iff \begin{cases} f(x) = g(x) \\ f(x) \ge 0 \end{cases}$

---

### 3. Показательные уравнения ($a > 0, \, a \neq 1$)
- Приведение к одному основанию:
- ### $a^{f(x)} = a^{g(x)} \iff f(x) = g(x)$
- Однородные уравнения 2-й степени ($A \cdot a^{2x} + B \cdot a^x b^x + C \cdot b^{2x} = 0$):
	- Деление на $b^{2x} \neq 0 \implies A\left(\frac{a}{b}\right)^{2x} + B\left(\frac{a}{b}\right)^x + C = 0$ с заменой $t = \left(\frac{a}{b}\right)^x > 0$.

---

### 4. Логарифмические уравнения ($a > 0, \, a \neq 1$)
- Простейшее:
- ### $\log_a f(x) = b \iff f(x) = a^b$
- Потенцирование:
- ### $\log_a f(x) = \log_a g(x) \iff \begin{cases} f(x) = g(x) \\ f(x) > 0 \end{cases}$
- Переменное основание:
- ### $\log_{h(x)} f(x) = \log_{h(x)} g(x) \iff \begin{cases} f(x) = g(x) \\ f(x) > 0 \\ h(x) > 0 \\ h(x) \neq 1 \end{cases}$
