## 1. Линейная функция: $f(x) = kx + b$
График — прямая линия.

### Алгоритм нахождения коэффициентов:
1. **Коэффициент $k$ (наклон прямой):**
	- Выбрать два целых узла сетки $(x_1; y_1)$ и $(x_2; y_2)$ на прямой:
- ### $k = \pm \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$
	- Знак: прямая возрастает $\implies k > 0$; убывает $\implies k < 0$.
2. **Коэффициент $b$ (свободный член / сдвиг):**
	- Пересечение прямой с осью $Oy$ (при $x = 0$):
- ### $b = f(0)$
	- Если точка пересечения с $Oy$ вне сетки — подставить найденный $k$ и узел $(x_1; y_1)$:
- ### $b = y_1 - k \cdot x_1$

## 2. Квадратичная функция (парабола)
Стандартный вид: $f(x) = ax^2 + bx + c$  
Вид через вершину $(x_0; y_0)$:
- ### $f(x) = a(x - x_0)^2 + y_0$

### Алгоритм нахождения коэффициентов:
1. **Координаты вершины $(x_0; y_0)$:**
	- Найти точку разворота параболы по сетке:
- ### $x_0 = -\frac{b}{2a}, \quad y_0 = f(x_0)$
2. **Коэффициент $a$ («правило шага» от вершины):**
	- От вершины сделать шаг на $1$ клетку вправо ($\Delta x = 1$):
- ### $a = \Delta y$
	- Если смещение не целое, сделать шаг на $2$ клетки вправо ($\Delta x = 2$):
- ### $a = \frac{\Delta y}{4}$
	- Знак: ветви вверх $\implies a > 0$; ветви вниз $\implies a < 0$.
3. **Коэффициент $c$:**
	- Точка пересечения параболы с осью $Oy$ (при $x = 0$):
- ### $c = f(0)$
4. **Коэффициент $b$:**
	- Находится через абсциссу вершины $x_0$ и найденный $a$:
- ### $b = -2a \cdot x_0$

## 3. Обратная пропорциональность (гипербола)
Смещённый вид:
- ### $f(x) = \frac{k}{x - x_0} + y_0$

### Алгоритм нахождения коэффициентов:
1. **Асимптоты $(x_0; y_0)$:**
	- Вертикальная асимптота: $x = x_0$ (знаменатель равен 0).
	- Горизонтальная асимптота: $y = y_0$.
2. **Коэффициент $k$:**
	- Выбрать один целый узел сетки $(x_1; y_1)$ на ветви гиперболы:
- ### $k = (x_1 - x_0) \cdot (y_1 - y_0)$
	- Знак: ветви в I и III четвертях относительно асимптот $\implies k > 0$; во II и IV $\implies k < 0$.

## 4. Функция квадратного корня
Смещённый вид:
- ### $f(x) = a\sqrt{x - x_0} + y_0$

### Алгоритм нахождения коэффициентов:
1. **Начальная точка ветви $(x_0; y_0)$:**
	- Координаты «носика» графика сразу дают сдвиги $x_0$ и $y_0$.
2. **Коэффициент $a$:**
	- От точки $(x_0; y_0)$ сделать шаг на $1$ клетку вправо ($\Delta x = 1$):
- ### $a = \Delta y$
	- При шаге на $4$ клетки вправо ($\Delta x = 4$):
- ### $a = \frac{\Delta y}{2}$
	- Знак: ветвь идёт вверх $\implies a > 0$; ветвь идёт вниз $\implies a < 0$.

---

## 5. Показательная функция
Вид со сдвигом:
- ### $f(x) = a^x + b$

### Алгоритм нахождения коэффициентов:
1. **Свободный член $b$ (горизонтальная асимптота):**
	- Горизонтальная прямая $y = b$, к которой прижимается пологий край графика (если $f(x) = a^x$, то $b = 0$).
2. **Опорная точка ($x = 0$):**
- ### $f(0) = a^0 + b = 1 + b$
3. **Основание $a$:**
	- Расстояние от графика до асимптоты при $x = 1$:
- ### $a = f(1) - b$
	- Либо подставить узел сетки $(x_1; y_1)$ в равенство:
- ### $a^{x_1} = y_1 - b$

---

## 6. Логарифмическая функция
Вид со сдвигом:
- ### $f(x) = \log_a (x - x_0) + b$

### Алгоритм нахождения коэффициентов:
1. **Сдвиг $x_0$ (вертикальная асимптота):**
	- Вертикальная прямая $x = x_0$, вдоль которой график уходит в бесконечность.
2. **Опорная точка ($x = x_0 + 1$):**
	- В точке с отступом на $1$ клетку вправо от асимптоты логарифм равен $0$:
- ### $f(x_0 + 1) = b$
3. **Основание $a$:**
	- Выбрать узел сетки $(x_1; y_1)$ и выразить основание:
- ### $a^{y_1 - b} = x_1 - x_0$

## 7. Тригонометрические функции (синус и косинус)
Общий вид:
- ### $f(x) = a \sin(b x + c) + d$
- ### $f(x) = a \cos(b x + c) + d$

### Алгоритм нахождения параметров:
1. **Вертикальный сдвиг $d$ (средняя линия колебаний):**
	- Находится как среднее арифметическое между верхним пиком $y_{\max}$ и нижним пиком $y_{\min}$:
- ### $d = \frac{y_{\max} + y_{\min}}{2}$
2. **Коэффициент $a$ (амплитуда):**
	- Высота волны от средней линии до пика:
- ### $|a| = \frac{y_{\max} - y_{\min}}{2} = y_{\max} - d$
	- Знак:
		- Для $\sin$: график выходит из средней линии вверх $\implies a > 0$; вниз $\implies a < 0$.
		- Для $\cos$: при $x = 0$ график имеет максимум $\implies a > 0$; минимум $\implies a < 0$.
3. **Коэффициент $b$ (частота через период $T$):**
	- Период $T$ — расстояние по горизонтали между двумя соседними максимумами (или соседними минимумами):
- ### $|b| = \frac{2\pi}{T}$
4. **Фазовый сдвиг $c$ (сдвиг по горизонтали):**
	- Подставить абсциссу известного максимума волны $x_0$ в аргумент функции:
- ### $c = \frac{\pi}{2} - b x_0 \quad (\text{для } \sin)$
- ### $c = -b x_0 \quad (\text{для } \cos)$

## 8. Тангенс: $f(x) = a \operatorname{tg}(b x) + d$

### Алгоритм нахождения коэффициентов:
1. **Коэффициент $b$ (период тангенса):**
	- Расстояние $T$ между двумя соседними вертикальными асимптотами:
- ### $|b| = \frac{\pi}{T}$
2. **Свободный член $d$ (точка перегиба):**
	- Ордината точки перегиба ветви (лежит ровно посередине между асимптотами):
- ### $d = f(x_{\text{центр}})$
3. **Коэффициент $a$:**
	- Смещение по вертикали при отступе на четверть периода ($\Delta x = \frac{T}{4}$) от точки перегиба:
- ### $a = f\left(x_{\text{центр}} + \frac{T}{4}\right) - d$
