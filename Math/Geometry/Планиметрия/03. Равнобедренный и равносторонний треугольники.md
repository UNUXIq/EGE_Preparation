# [[MoC Планиметрия|Планиметрия]] :: Равнобедренный и равносторонний треугольники

> [!abstract] Ключевая концепция
> Симметрия этих треугольников позволяет мгновенно сводить большинство задач Задания 1 к **прямоугольным треугольникам** через проведение высоты к основанию.

---

## 1. Равнобедренный треугольник

Треугольник называется равнобедренным, если две его стороны равны ($a = b$ — боковые стороны, $c$ — основание).

### Основные свойства:
1. **Углы при основании равны:** $\angle A = \angle B = \alpha$.
   * Угол при вершине: $\gamma = 180^\circ - 2\alpha$.
   * Углы при основании всегда **острые** ($\alpha < 90^\circ$).
2. **Внешний угол при вершине:** равен удвоенному углу при основании:
   $$\angle \text{внеш}_\gamma = 2\alpha$$
3. **Высота к основанию:** является одновременно **медианой, биссектрисой и серединным перпендикуляром**:
   $$h_c = m_c = l_c$$

> [!tip] Главный алгоритм решения в Задании 1
> Проведение высоты $CH \perp AB$ делит основание пополам ($AH = HB = \frac{c}{2}$) и разбивает равнобедренный треугольник на **два равных прямоугольных треугольника** $\triangle AHC = \triangle BHC$.  
> Все элементы находятся через этот прямоугольный треугольник:
> * Высота: $h = \sqrt{a^2 - \left(\frac{c}{2}\right)^2}$
> * Тригонометрия угла при основании:
>   $$\cos \alpha = \frac{c / 2}{a} = \frac{c}{2a}, \quad \sin \alpha = \frac{h}{a}, \quad \mathrm{tg}\,\alpha = \frac{h}{c / 2} = \frac{2h}{c}$$

### Площадь равнобедренного треугольника:
$$S = \frac{1}{2} c h_c$$
$$S = \frac{1}{2} a^2 \sin \gamma \quad (\text{через угол при вершине})$$

## 2. Равносторонний (правильный) треугольник

Треугольник, у которого все три стороны равны ($a = b = c$). Все углы равны $60^\circ$.

Все высоты являются медианами, биссектрисами и пересекаются в **единой точке** — центре треугольника (центры вписанной и описанной окружностей совпадают).

### Экспресс-формулы для КИМ ЕГЭ:
Любой элемент выражается напрямую через сторону $a$:

| Элемент | Формула | Через высоту $h$ |
| :--- | :---: | :---: |
| **Высота / медиана / биссектриса** | $h = \dfrac{a\sqrt{3}}{2}$ | $h$ |
| **Площадь** | $S = \dfrac{a^2\sqrt{3}}{4}$ | $S = \dfrac{h^2}{\sqrt{3}} = \dfrac{h^2\sqrt{3}}{3}$ |
| **Радиус описанной окружности** | $R = \dfrac{a\sqrt{3}}{3}$ | $R = \dfrac{2}{3}h$ |
| **Радиус вписанной окружности** | $r = \dfrac{a\sqrt{3}}{6}$ | $r = \dfrac{1}{3}h$ |

> [!important] Взаимосвязь радиусов и высоты
> В правильном треугольнике высота делится центром в отношении $2 : 1$:
> $$R = 2r$$
> $$h = R + r = 3r = \frac{3}{2}R$$

## 3. Опорные конструкции в равнобедренных треугольниках

### Конструкция с углом $120^\circ$ при вершине
Если угол при вершине равен $120^\circ$, то углы при основании равны по $30^\circ$:
* Высота к основанию: $h = \frac{a}{2}$ (катет против угла $30^\circ$).
* Основание: $c = 2 \cdot (a \cos 30^\circ) = a\sqrt{3}$.
* Радиус описанной окружности равен боковой стороне:
  $$R = \frac{c}{2\sin 120^\circ} = \frac{a\sqrt{3}}{2 \cdot \frac{\sqrt{3}}{2}} = a$$

### Свойство высот к боковым сторонам
Высоты, проведённые к боковым сторонам, равны между собой ($h_a = h_b$).  
Связь высот через площадь:
$$a \cdot h_a = c \cdot h_c \implies h_a = \frac{c \cdot h_c}{a}$$

> [!example] Типичные ловушки в Задании 1
> 1. **Внешний угол при основании:**  
>    В равнобедренном треугольнике $ABC$ ($AC = BC$) дан внешний угол при вершине $B$, равный $120^\circ$. Найдите угол $C$.  
>    *Ошибка:* считать, что углы при основании равны $120^\circ$.  
>    *Верно:* внутренний угол при основании равен $180^\circ - 120^\circ = 60^\circ$. Тогда углы при основании по $60^\circ \implies$ треугольник равносторонний $\implies \angle C = 60^\circ$.
> 2. **Отрицательный косинус тупого угла:**  
>    Если в равнобедренном треугольнике дан тупой угол $\gamma$ при вершине (например, $\cos \gamma = -0{,}6$), боковые стороны равны $a$. Для поиска основания $c$ применяйте **теорему косинусов**:
>    $$c^2 = a^2 + a^2 - 2a^2 \cos \gamma = 2a^2(1 - \cos \gamma)$$
>    Минус на минус даёт плюс: $c^2 = 2a^2(1 - (-0{,}6)) = 3{,}2a^2$.
> 3. **Путаница $R$ и $r$ в правильном треугольнике:**  
>    Центр делит высоту на части $R$ (сверху, $\frac{2}{3}$) и $r$ (снизу, $\frac{1}{3}$). Всегда проверяйте: **радиус описанной окружности в 2 раза больше радиуса вписанной**.
