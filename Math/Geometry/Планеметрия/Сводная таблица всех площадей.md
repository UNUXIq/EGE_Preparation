# [[MoC Планиметрия|Планиметрия]] :: Сводная таблица всех площадей

> [!abstract] Обозначения
> * $a, b, c$ — стороны фигур;
> * $h_a$ — высота, проведённая к стороне $a$;
> * $p$ — полупериметр ($p = \frac{a + b + c}{2}$ или $p = \frac{P}{2}$);
> * $R$ — радиус описанной окружности;
> * $r$ — радиус вписанной окружности;
> * $d_1, d_2$ — диагонали, $\varphi$ — угол между диагоналями.

---

## 1. Площади треугольников

| Тип треугольника                     |                        Формула                        | Особенности и применение                                           |
| :----------------------------------- | :---------------------------------------------------: | :----------------------------------------------------------------- |
| **Любой треугольник**                |               $S = \dfrac{1}{2} a h_a$                | Базовая формула через сторону и проведённую к ней высоту  |
| **Любой треугольник**                |      $S = \dfrac{1}{2} ab \sin \gamma$       | Через две стороны и синус угла между ними                 |
| **Формула Герона**                   |        $S = \sqrt{p(p-a)(p-b)(p-c)}$         | Используется, если даны три стороны без углов             |
| **Через вписанную окружность ($r$)** |               $S = p \cdot r$                | $p$ — полупериметр; выражает $r = \dfrac{S}{p}$                    |
| **Через описанную окружность ($R$)** |            $S = \dfrac{abc}{4R}$             | Позволяет найти радиус: $R = \dfrac{abc}{4S}$                      |
| **Прямоугольный**                    |            $S = \dfrac{1}{2} ab$             | Половина произведения катетов                             |
| **Прямоугольный**                    |               $S = \dfrac{1}{2} c h_c$                | Через гипотенузу $c$ и высоту к ней $h_c$                          |
| **Равнобедренный**                   |          $S = \dfrac{1}{2} a^2 \sin \gamma$           | Через боковые стороны $a$ и угол при вершине $\gamma$              |
| **Равносторонний (правильный)**      | $S = \dfrac{a^2\sqrt{3}}{4} = \dfrac{h^2\sqrt{3}}{3}$ | Экспресс-счёт без вычисления углов                                 |

## 2. Площади четырёхугольников

| Фигура                                |                 Формула                 | Особенности и применение                                    |
| :------------------------------------ | :-------------------------------------: | :---------------------------------------------------------- |
| **Любой выпуклый четырёхугольник**    | $S = \dfrac{1}{2} d_1 d_2 \sin \varphi$ | Через диагонали и любой угол $\varphi$ между ними           |
| **Описанный четырёхугольник**         |    $S = p \cdot r = (a + c) \cdot r$    | Так как $a + c = b + d = p$                                 |
| **Параллелограмм**                    |     $S = a \cdot h_a = b \cdot h_b$     | Произведение стороны на высоту к ней                        |
| **Параллелограмм**                    |          $S = ab \sin \alpha$           | Через смежные стороны и угол между ними                     |
| **Параллелограмм**                    | $S = \dfrac{1}{2} d_1 d_2 \sin \varphi$ | Через диагонали и угол между ними                           |
| **Прямоугольник**                     |             $S = a \cdot b$             | Произведение смежных сторон                                 |
| **Прямоугольник**                     |   $S = \dfrac{1}{2} d^2 \sin \varphi$   | Диагонали равны ($d_1 = d_2 = d$)                           |
| **Ромб**                              |       $S = \dfrac{1}{2} d_1 d_2$        | Так как диагонали перпендикулярны ($\sin 90^\circ = 1$)     |
| **Ромб**                              |      $S = a \cdot h = 2a \cdot r$       | Высота ромба равна диаметру вписанной окружности ($h = 2r$) |
| **Ромб**                              |          $S = a^2 \sin \alpha$          | Через сторону и любой внутренний угол                       |
| **Квадрат**                           |       $S = a^2 = \dfrac{d^2}{2}$        | Сторона $a$ или диагональ $d = a\sqrt{2}$                   |
| **Трапеция**                          |     $S = \dfrac{a + b}{2} \cdot h$      | Полусумма оснований на высоту                               |
| **Трапеция**                          |             $S = m \cdot h$             | Средняя линия $m = \dfrac{a + b}{2}$ на высоту              |
| **Трапеция ($d_1 \perp d_2$, равн.)** |             $S = h^2 = m^2$             | Высота равна средней линии                                  |

## 3. Многоугольники, круг и сектор

| Фигура | Формула | Пояснение |
| :--- | :---: | :--- |
| **Правильный шестиугольник** | $S = \dfrac{3\sqrt{3}a^2}{2}$ | Площадь 6 правильных треугольников со стороной $a$ |
| **Правильный $n$-угольник** | $S = p \cdot r = \dfrac{1}{2} P r$ | $p$ — полупериметр, $r$ — апофема (радиус вписанной) |
| **Круг** | $S = \pi R^2 = \dfrac{\pi D^2}{4}$  | $R$ — радиус, $D$ — диаметр |
| **Круговой сектор** | $S = \dfrac{\pi R^2}{360^\circ} \cdot \alpha = \dfrac{1}{2} l R$  | $\alpha$ — градусная мера дуги, $l$ — длина дуги  |

## 4. Отношения площадей (опорные теоремы и леммы)

> [!important] Теоремы для решения задач без вычисления сторон
> 1. **Подобие фигур:**  
>    Отношение площадей подобных фигур равно квадрату коэффициента подобия :
>    $$\frac{S_1}{S_2} = k^2$$ 
>    *(Если средняя линия делит стороны с коэффициентом $k = \frac{1}{2}$, то $S_{\text{отсеч}} = \frac{1}{4} S_{\text{исх}}$, а $S_{\text{трап}} = \frac{3}{4} S_{\text{исх}}$).*
>
> 2. **Общая (или равная) высота:**  
>    Если треугольники имеют общую высоту, их площади относятся как основания :
>    $$\frac{S_1}{S_2} = \frac{a_1}{a_2}$$
>
> 3. **Общий (или равный) угол:**  
>    Если угол одного треугольника равен углу другого треугольника, их площади относятся как произведения заключающих этот угол сторон :
>    $$\frac{S_{\triangle ADE}}{S_{\triangle ABC}} = \frac{AD \cdot AE}{AB \cdot AC}$$
>
> 4. **Медиана треугольника:**  
>    * Одна медиана делит треугольник на **два равновеликих** ($S_1 = S_2$).
>    * Три медианы разбивают треугольник на **шесть равновеликих** ($S_i = \frac{1}{6} S_{\triangle}$).
>
> 5. **Диагонали в трапеции:**  
>    Диагонали делят трапецию на 4 треугольника:
>    * При основаниях: $\triangle AOD \sim \triangle COB \implies \dfrac{S_1}{S_2} = \left(\dfrac{a}{b}\right)^2$.
>    * Боковые треугольники равновелики: $S_{\text{бок1}} = S_{\text{бок2}} = \sqrt{S_1 \cdot S_2}$.
>    * Вся площадь: $S_{\text{трап}} = (\sqrt{S_1} + \sqrt{S_2})^2$.
>
> 6. **Доли в правильном шестиугольнике площади $S$:**  
>    * Отсечённый угол ($\triangle ABC$): $S_1 = \dfrac{1}{6} S$.
>    * Треугольник через вершины через одну ($\triangle ACE$): $S_2 = \dfrac{1}{2} S$.
>    * Прямоугольник из двух малых диагоналей ($ABDE$): $S_3 = \dfrac{2}{3} S$.

> [!example] Типичные ловушки при расчёте площадей в Задании 1
> 1. **Забытая половина в формулах:**  
>    В треугольниках и четырёхугольниках через диагонали коэффициент $\frac{1}{2}$ обязателен:  
>    $S_{\triangle} = \mathbf{\frac{1}{2}} ah$ , $S_{\text{чет}} = \mathbf{\frac{1}{2}} d_1 d_2 \sin \varphi$ .  
>    В параллелограмме половины нет: $S = ah$ , $S = ab \sin \alpha$ .
> 2. **Коэффициент подобия площадей:**  
>    Если линейные размеры фигуры увеличили в $3$ раза, её площадь увеличивается в $3^2 = 9$ раз, а не в $3$ раза.
> 3. **Высота трапеции через диаметр:**  
>    Если в равнобедренную или прямоугольную трапецию вписана окружность радиуса $r$, высота трапеции всегда равна $h = 2r$.
