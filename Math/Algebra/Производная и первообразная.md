## 1. Физический смысл производной

Если координата точки при прямолинейном движении задана уравнением $x(t)$ (или $s(t)$):
* **Мгновенная скорость** — первая производная координаты по времени:
  $$v(t) = x'(t)$$
* **Ускорение** — производная скорости (вторая производная координаты):
  $$a(t) = v'(t) = x''(t)$$

### Типовые формулировки и алгоритмы:
| Задача | Что делать |
| :--- | :--- |
| **Найти скорость в момент времени $t = t_0$** | 1. Находим формулу $v(t) = x'(t)$<br>2. Подставляем $t_0$: считаем $v(t_0)$ |
| **В какой момент времени скорость была $v_0$?** | 1. Находим $x'(t)$<br>2. Составляем уравнение $x'(t) = v_0$<br>3. Находим $t$ (учитываем $t \ge 0$) |
| **В какой момент точка остановилась?** | Остановка $\iff v(t) = 0 \implies x'(t) = 0$ |

> [!warning] Ловушка со временем
> Время физически не может быть отрицательным ($t \ge 0$). Если квадратное уравнение дает корни разных знаков, отрицательный отбрасываем сразу. Если оба положительные — перечитываем условие (обычно требуется «в первый раз» или момент в заданном интервале).

## 2. Геометрический смысл производной и касательная

> [!important] Главная формула
> Значение производной функции $y = f(x)$ в точке касания $x_0$ равно угловому коэффициенту касательной $k$ и тангенсу угла наклона $\alpha$ этой прямой к положительному направлению оси $Ox$:
> $$f'(x_0) = k = \operatorname{tg} \alpha$$

### 1. Поиск $f'(x_0)$ по чертежу (по клеткам):
1. На прямой касательной находим **две отмеченные точки** в узлах сетки $(x_1; y_1)$ и $(x_2; y_2)$.
2. Достраиваем по ним прямоугольный треугольник с катетами $\Delta y = |y_2 - y_1|$ и $\Delta x = |x_2 - x_1|$.
3. Считаем значение с учетом направления прямой:
   * Касательная **возрастает** (снизу вверх $\nearrow$, угол острый) $\implies f'(x_0) = +\dfrac{\Delta y}{\Delta x}$
   * Касательная **убывает** (сверху вниз $\searrow$, угол тупой) $\implies f'(x_0) = -\dfrac{\Delta y}{\Delta x}$

### 2. Уравнение касательной:
$$y = f'(x_0)(x - x_0) + f(x_0)$$

### 3. Условия параллельности и касания:
* **Касательная параллельна прямой $y = kx + b$ (или совпадает с ней):**
  $$f'(x_0) = k$$
* **Прямая $y = kx + b$ является касательной к $y = f(x)$:**
  $$\begin{cases} f'(x) = k \\ f(x) = kx + b \end{cases}$$
  *(Из первого уравнения находим кандидатов на точку касания $x$, во второе подставляем для отбора подходящего).*

## 3. Применение производной к исследованию функций

> [!danger] Первое действие перед решением
> Всегда смотрите на подпись к оси ординат или в текст задачи:
> **Дан график самой функции $y = f(x)$ или график ее производной $y = f'(x)$?**

### Сводная таблица чтения графиков

| Характеристика | График ФУНКЦИИ $y = f(x)$ | График ПРОИЗВОДНОЙ $y = f'(x)$ |
| :--- | :--- | :--- |
| **Возрастание функции** | Линия идет вверх $\nearrow$ | График строго **выше оси $Ox$** ($f'(x) > 0$) |
| **Убывание функции** | Линия идет вниз $\searrow$ | График строго **ниже оси $Ox$** ($f'(x) < 0$) |
| **Точки экстремума (стационарные)** | «Вершины» холмов и «дно» впадин (касательная горизонтальна) | Точки **пересечения с осью $Ox$** ($f'(x) = 0$) |
| **Точка максимума** | Вершина холма $\cap$ | Пересечение с $Ox$, где знак меняется с **$+$ на $-$** |
| **Точка минимума** | Дно оврага $\cup$ | Пересечение с $Ox$, где знак меняется с **$-$ на $+$** |
| **Наибольшее значение на отрезке $[a; b]$** | Самая верхняя точка графика на интервале | Если $f'(x) \ge 0 \implies$ в правом конце $b$;<br>Если $f'(x) \le 0 \implies$ в левом конце $a$ |
| **Наименьшее значение на отрезке $[a; b]$** | Самая нижняя точка графика на интервале | Если $f'(x) \ge 0 \implies$ в левом конце $a$;<br>Если $f'(x) \le 0 \implies$ в правом конце $b$ |

> [!warning] Самая частая ошибка на графике производной
> Вершины («холмы») и впадины на графике производной $y = f'(x)$ **не являются экстремумами функции $f(x)$**!  
> В этих точках функция лишь меняет скорость изменения. Экстремумы $f(x)$ живут **только на оси $Ox$**.

> [!tip] Внимание к границам отрезка
> В вопросах типа «Найдите количество точек экстремума на отрезке $[-3; 5]$»:
> 1. Проведите вертикальные прямые через концы отрезка (ограничьте рабочую зону).
> 2. Считайте только точки **строго внутри или на границах** этого интервала.

## 4. Первообразная и площадь

Функция $F(x)$ называется первообразной для $f(x)$ на промежутке, если:
$$F'(x) = f(x)$$

> [!important] Золотое правило связи
> **Первообразная $F(x)$ относится к функции $f(x)$ в точности так же, как сама функция $f(x)$ относится к своей производной $f'(x)$:**
> * $f(x) > 0 \implies F(x)$ возрастает;
> * $f(x) < 0 \implies F(x)$ убывает;
> * $f(x) = 0 \implies$ точки экстремума первообразной $F(x)$.

### Формула Ньютона — Лейбница (Геометрический смысл определенного интеграла)
Площадь фигуры под графиком функции $y = f(x)$ на отрезке $[a; b]$:
$$S = \int_a^b f(x)\,dx = F(b) - F(a)$$

#### Алгоритм решения прототипов на площадь:
1. По рисунку определяем границы фигуры по оси $Ox$: левая граница $a$, правая граница $b$.
2. В заданную формулу первообразной $F(x)$ подставляем сначала $b$, затем $a$.
3. Находим разность $F(b) - F(a)$ (свободный член $C$ всегда взаимно уничтожается).
