## 1. Степени и их свойства

Пусть $a > 0, b > 0$, а $m, n \in \mathbb{R}$:

| Свойство | Формула | Пример / Пояснение |
| :--- | :---: | :--- |
| **Произведение с равным основанием** | $a^m \cdot a^n = a^{m+n}$ | $2^3 \cdot 2^4 = 2^7 = 128$ |
| **Частное с равным основанием** | $\dfrac{a^m}{a^n} = a^{m-n}$ | $\dfrac{5^8}{5^6} = 5^2 = 25$ |
| **Возведение степени в степень** | $(a^m)^n = a^{m \cdot n}$ | $(3^2)^3 = 3^6 = 729$ |
| **Степень произведения** | $(a \cdot b)^n = a^n \cdot b^n$ | $6^x = (2 \cdot 3)^x = 2^x \cdot 3^x$ |
| **Степень частного** | $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ | $\left(\dfrac{2}{5}\right)^3 = \dfrac{8}{125}$ |
| **Отрицательная степень** | $a^{-n} = \dfrac{1}{a^n}, \quad \left(\dfrac{a}{b}\right)^{-n} = \left(\dfrac{b}{a}\right)^n$ | $2^{-3} = \dfrac{1}{8}; \quad \left(\dfrac{2}{3}\right)^{-2} = \dfrac{9}{4}$ |
| **Нулевая степень** | $a^0 = 1 \quad (a \ne 0)$ | $7^0 = 1, \quad (-12)^0 = 1$ |

## 2. Корни и дробные показатели

| Свойство | Формула | Ограничения |
| :--- | :---: | :--- |
| **Связь корня со степенью** | $\sqrt[n]{a^m} = a^{\frac{m}{n}}$ | $a > 0, n \in \mathbb{N}, n \ge 2$ |
| **Корень из произведения** | $\sqrt[n]{a \cdot b} = \sqrt[n]{a} \cdot \sqrt[n]{b}$ | $a \ge 0, b \ge 0$ |
| **Корень из дроби** | $\sqrt[n]{\dfrac{a}{b}} = \dfrac{\sqrt[n]{a}}{\sqrt[n]{b}}$ | $a \ge 0, b > 0$ |
| **Корень из корня** | $\sqrt[m]{\sqrt[n]{a}} = \sqrt[m \cdot n]{a}$ | $a \ge 0$ |
| **Внесение под корень** | $a\sqrt[n]{b} = \sqrt[n]{a^n \cdot b}$ | При чётном $n$: $a \ge 0$ |

> [!warning] Модуль при извлечении корня чётной степени
> * Для чётной степени:
>   $$\sqrt[2k]{a^{2k}} = |a|$$
> * Для нечётной степени:
>   $$\sqrt[2k+1]{a^{2k+1}} = a$$
> 
> **Типичная задача ЕГЭ:** Упростить $\sqrt{(x - 7)^2}$ при $x < 7$.  
> Так как $x < 7 \implies x - 7 < 0$, модуль раскрывается с противоположным знаком:
> $$\sqrt{(x - 7)^2} = |x - 7| = -(x - 7) = 7 - x$$

## 3. Формулы сокращённого умножения (ФСУ) и факторизация

* **Квадрат суммы / разности:**
  $$(a \pm b)^2 = a^2 \pm 2ab + b^2$$
* **Разность квадратов:**
  $$a^2 - b^2 = (a - b)(a + b)$$
* **Сумма / разность кубов:**
  $$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$$
* **Куб суммы / разности:**
  $$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$$
* **Разложение квадратного трёхчлена на множители:**
  $$ax^2 + bx + c = a(x - x_1)(x - x_2)$$
  где $x_1, x_2$ — корни уравнения $ax^2 + bx + c = 0$.

## 4. Логарифмы: Определение и все свойства

> [!abstract] Определение логарифма
> Логарифм по основанию $a$ от числа $b$ — это показатель степени, в которую нужно возвести $a$, чтобы получить $b$:
> $$\log_a b = c \iff a^c = b \quad (a > 0, a \ne 1, b > 0)$$

### Сводная таблица свойств логарифмов

| Свойство | Формула | Пояснение / Пример |
| :--- | :---: | :--- |
| **Основное логарифмическое тождество** | $a^{\log_a b} = b$ | $3^{\log_3 7} = 7$ |
| **Тождество перестановки** | $a^{\log_c b} = b^{\log_c a}$ | $2^{\log_3 5} = 5^{\log_3 2}$ |
| **Логарифм единицы** | $\log_a 1 = 0$ | $a^0 = 1$ |
| **Логарифм основания** | $\log_a a = 1$ | $a^1 = a$ |
| **Логарифм обратного числа** | $\log_a \dfrac{1}{a} = -1$ | $a^{-1} = \frac{1}{a}$ |
| **Сумма логарифмов** | $\log_a b + \log_a c = \log_a (b \cdot c)$ | Складываем $\to$ аргументы умножаются |
| **Разность логарифмов** | $\log_a b - \log_a c = \log_a \left(\dfrac{b}{c}\right)$ | Вычитаем $\to$ аргументы делятся |
| **Вынос степени аргумента** | $\log_a (b^m) = m \cdot \log_a b$ | $b > 0$; если $m$ чётное и знак $b$ неизвестен: $m\log_a \|b\|$ |
| **Вынос степени основания** | $\log_{a^k} b = \dfrac{1}{k} \cdot \log_a b$ | Степень основания выходит в знаменатель |
| **Комбинация степеней** | $\log_{a^k} (b^m) = \dfrac{m}{k} \cdot \log_a b$ | $\log_{8} 16 = \log_{2^3} (2^4) = \dfrac{4}{3}$ |
| **Переход к новому основанию** | $\log_a b = \dfrac{\log_c b}{\log_c a}$ | Позволяет ввести любое удобное основание $c$ |
| **Обратный логарифм** | $\log_a b = \dfrac{1}{\log_b a}$ | $\log_2 5 = \dfrac{1}{\log_5 2}$ |
| **Произведение взаимно обратных** | $\log_a b \cdot \log_b a = 1$ | Сокращение цепочки: $\log_a b \cdot \log_b c = \log_a c$ |
| **Свойство перестановки оснований** | $\log_a b \cdot \log_c d = \log_c b \cdot \log_a d$ | Удобно группировать множители |

## 5. Методы решения уравнений (Задание 7)

### 1. Дробно-рациональные уравнения
Уравнение вида $\dfrac{A(x)}{B(x)} = \dfrac{C(x)}{D(x)}$:
* Решается умножением «крест-накрест»: $A(x) \cdot D(x) = B(x) \cdot C(x)$;
* **ОДЗ:** $B(x) \ne 0$ и $D(x) \ne 0$. Обязательно исключаем корни, обращающие знаменатель в $0$.

### 2. Иррациональные уравнения
* Базовый вид: $\sqrt{f(x)} = g(x)$  
  $$\sqrt{f(x)} = g(x) \iff \begin{cases} f(x) = (g(x))^2 \\ g(x) \ge 0 \end{cases}$$
  > [!tip] Практический приём
  > Если справа стоит просто положительное число ($\sqrt{f(x)} = a, a \ge 0$), то сразу возводим в квадрат: $f(x) = a^2$.  
  > Всегда делайте **проверку подстановкой** найденных корней в исходное уравнение.

### 3. Показательные уравнения
* Приводим обе части к одному основанию:
  $$a^{f(x)} = a^{g(x)} \implies f(x) = g(x) \quad (a > 0, a \ne 1)$$
* Опорные степени:
  * Степени двойки: $2^2=4, 2^3=8, 2^4=16, 2^5=32, 2^6=64, 2^7=128, 2^8=256$;
  * Степени тройки: $3^2=9, 3^3=27, 3^4=81, 3^5=243$;
  * Степени пятёрки: $5^2=25, 5^3=125, 5^4=625$.

### 4. Логарифмические уравнения
* **По определению:**
  $$\log_a f(x) = b \implies f(x) = a^b \quad (\text{ОДЗ } f(x) > 0 \text{ выполняется автоматически, так как } a^b > 0)$$
* **Потенцирование:**
  $$\log_a f(x) = \log_a g(x) \iff \begin{cases} f(x) = g(x) \\ f(x) > 0 \end{cases}$$
