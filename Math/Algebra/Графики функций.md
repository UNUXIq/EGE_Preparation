> [!abstract] Специфика Задания 12
> Задание повышенного уровня сложности первой части с кратким ответом (1 первичный балл).
> **Главная цель:** быстро и безошибочно восстановить аналитическую формулу функции по её графику на координатной сетке и ответить на вопрос задачи:
> 1. Вычислить значение $f(x_0)$ при заданном аргументе;
> 2. Найти аргумент $x$, при котором $f(x) = y_0$;
> 3. Найти координаты (абсциссу или ординату) точки пересечения двух графиков.

## 1. Линейная функция: $f(x) = kx + b$

### Алгоритм определения коэффициентов:
1. **Угловой коэффициент $k$ (тангенс наклона):**
   * Находим две отмеченные точки на прямой с целыми координатами: $A(x_1; y_1)$ и $B(x_2; y_2)$.
   * Достраиваем прямоугольный треугольник:
     $$k = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$$
   * Знак $k$: если прямая идёт вверх $\nearrow$ — знак $+$, если вниз $\searrow$ — знак $-$.
2. **Свободный коэффициент $b$:**
   * Геометрически $b$ — ордината пересечения прямой с осью $Oy$ (при $x = 0$).
   * Если пересечение не видно на сетке, подставляем любую из точек:
     $$b = y_1 - k \cdot x_1$$

## 2. Квадратичная функция (парабола): $f(x) = ax^2 + bx + c$

> [!tip] Экспресс-метод через вершину параболы
> Не составляйте систему из 3 уравнений. Используйте формулу сдвига вершины $(x_0; y_0)$:
> $$f(x) = a(x - x_0)^2 + y_0$$

### Алгоритм:
1. **Считываем вершину $(x_0; y_0)$** прямо по узлам координатной сетки.
2. **Находим старший коэффициент $a$ по таблице смещений:**
   Встаем в вершину и делаем шаг вправо на $\Delta x$:
   * шаг на $1$ вправо: смещение по вертикали равно $a \cdot 1^2 = a$;
   * шаг на $2$ вправо: смещение по вертикали равно $a \cdot 2^2 = 4a \implies a = \dfrac{\Delta y}{4}$.
   *(Если ветви вверх — $a > 0$, если ветви вниз — $a < 0$)*.
3. **Восстановление канонического вида $ax^2 + bx + c$ (при необходимости):**
   * $c$ — точка пересечения с осью $Oy$ (значение $f(0)$);
   * $b = -2a \cdot x_0$.

---

## 3. Обратная пропорциональность (гипербола): $f(x) = \frac{k}{x + a} + b$

График определяется положением двух его **асимптот**:

### Алгоритм нахождения коэффициентов:
1. **Вертикальная асимптота $x = x_{\text{ас}}$:**
   * Линия разрыва графика: $x + a = 0 \implies a = -x_{\text{ас}}$.
   * *Пример:* асимптота проходит через $x = 3 \implies a = -3$.
2. **Горизонтальная асимптота $y = y_{\text{ас}}$:**
   * Горизонтальная линия, к которой ветви прижимаются на бесконечности:
     $$b = y_{\text{ас}}$$
3. **Коэффициент $k$ (метод смещенного центра):**
   * Точка пересечения асимптот $C(x_{\text{ас}}; y_{\text{ас}})$ служит новым центром координат.
   * Выбираем отмеченную на ветви точку $(x_1; y_1)$ и перемножаем её отклонения от центра:
     $$k = (x_1 - x_{\text{ас}}) \cdot (y_1 - y_{\text{ас}})$$

> [!note] Вид дроби $f(x) = \frac{kx + a}{x + b}$
> Вертикальная асимптота: $x = -b$. Горизонтальная асимптота: $y = k$. Свободное число $a$ находится подстановкой отмеченной точки.

## 4. Функция квадратного корня: $f(x) = a\sqrt{x + b} + c$

График представляет собой полупараболу, направленную вправо.

### Алгоритм:
1. **Начало луча (вершина):**
   Точка старта графика имеет точные координаты:
   $$(x_{\text{нач}}; y_{\text{нач}}) = (-b; c) \implies b = -x_{\text{нач}}, \quad c = y_{\text{нач}}$$
2. **Коэффициент $a$:**
   * От точки старта отступаем на $1$ клетку вправо: смещение по вертикали равно $a$.
   * Отступаем на $4$ клетки вправо: смещение по вертикали равно $2a \implies a = \dfrac{\Delta y}{2}$.
   *(Если график уходит вниз, то $a < 0$)*.

## 5. Показательные и логарифмические функции

### А. Показательная функция: $f(x) = a^x + b$ или $f(x) = a^{x + b}$
1. **Горизонтальная асимптота:**
   Линия $y = b$, ниже (или выше) которой график не опускается $\implies$ сразу даёт параметр $b$.
2. **Основание степени $a$:**
   Берём отмеченную точку $(x_1; y_1)$ и подставляем в уравнение:
   $$y_1 - b = a^{x_1}$$
   *(В задачах ЕГЭ основание $a$ практически всегда равно $2, 3, \frac{1}{2}$ или $\frac{1}{3}$)*.

### Б. Логарифмическая функция: $f(x) = \log_a (x + b) + c$
1. **Вертикальная асимптота:**
   Прямая $x = -b$, левее которой график не существует $\implies b = -x_{\text{ас}}$.
2. **Опорная точка (где аргумент равен 1):**
   При $x + b = 1 \implies \log_a(1) = 0 \implies y = c$.
3. **Основание $a$:**
   Подставляем вторую отмеченную точку $(x_1; y_1)$:
   $$y_1 - c = \log_a(x_1 + b) \implies a^{y_1 - c} = x_1 + b$$

## 6. Тригонометрические функции: $f(x) = a\sin x + b$ или $a\cos x + b$

График — синусоида/косинусоида, колеблющаяся между $y_{\min}$ и $y_{\max}$.

### Алгоритм:
1. **Сдвиг по вертикали (средняя линия):**
   $$b = \frac{y_{\max} + y_{\min}}{2}$$
2. **Амплитуда $|a|$:**
   $$|a| = \frac{y_{\max} - y_{\min}}{2}$$
3. **Знак коэффициента $a$:**
   * Для $\sin x$: в точке $x = 0$ (или в начале периода) при $a > 0$ волна возрастает, при $a < 0$ — убывает.
   * Для $\cos x$: в точке $x = 0$ при $a > 0$ достигается максимум, при $a < 0$ — минимум.

## 7. Комбинированные задачи (точки пересечения)

Сюжет: даны графики двух функций $f(x)$ и $g(x)$, пересекающиеся в точках $A$ и $B$. Точка $B$ видна на чертеже, требуется найти координаты точки $A$.

### Универсальный алгоритм:
1. Восстанавливаем формулы обеих функций $f(x)$ и $g(x)$.
2. Приравниваем их и составляем уравнение пересечения:
   $$f(x) = g(x)$$
3. Решаем полученное квадратное уравнение:
   * Корень $x_B$ **уже известен из чертежа** — это даёт 100% гарантию проверки правильности формул!
   * Используем **теорему Виета**:
     $$x_A + x_B = -\frac{B}{A} \implies x_A = -\frac{B}{A} - x_B$$
     *(Это позволяет найти $x_A$ устно без вычисления дискриминанта)*.
4. **Внимание на вопрос задачи:**
   * «Найдите **абсциссу** точки $A$» $\implies$ пишем найденный $x_A$.
   * «Найдите **ординату** точки $A$» $\implies$ обязательно вычисляем $y_A = g(x_A)$, подставив $x_A$ в более простую функцию.
