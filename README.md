# ПОдготовка к ЕГЭ
Этот репозиторий был создан для подготовки к ЕГЭ по проф. мат., физике, русскому и информатике (2027)
---
## Что входит? 
- Теория по каждому заданию 
- Разборы задач 
- Готовые таблицы .csv для запоминания формул с помощью Anki
- Шаблоны решений
## О материалах
