# Кинематика

## 1. Основные понятия и модели кинематики

### 1.1. Материальная точка
Тело, геометрическими размерами и формой которого в условиях рассматриваемой задачи можно пренебречь.
* **Условия применимости модели:**
  1. Линейные размеры тела $d$ многократно меньше расстояния $L$, проходимого телом или разделяющего его с другими телами ($d \ll L$).
  2. Тело движется поступательно (любая прямая, жестко связанная с телом, остается параллельной самой себе).

### 1.2. Радиус-вектор, перемещение и путь
* **Радиус-вектор $\vec{r}(t)$:**
  ### $$\vec{r}(t) = (x(t), y(t), z(t))$$
* **Вектор перемещения $\Delta\vec{r}$:**
  ### $$\Delta\vec{r} = \vec{r}(t_2) - \vec{r}(t_1) = (\Delta x, \Delta y, \Delta z)$$
* **Пройденный путь $s$:** длина участка траектории, скалярная неотрицательная величина ($s \ge 0$).
* **Связь пути и перемещения:**
  ### $$s \ge |\Delta\vec{r}|$$
  *Равенство $s = |\Delta\vec{r}|$ строго выполняется только при прямолинейном движении в одном неизменном направлении.*

### 1.3. Скорость и ускорение (кинематические определения)
* **Мгновенная скорость:** 
### $$\vec{v} = \lim_{\Delta t \to 0} \frac{\Delta\vec{r}}{\Delta t} = \vec{r}'(t) = (v_x, v_y, v_z)$$
  
  ### $$v_x = x'(t), \quad v_y = y'(t), \quad v_z = z'(t)$$
  *Направлена по касательной к траектории в сторону движения.*
* **Мгновенное ускорение:**
  ### $$\vec{a} = \lim_{\Delta t \to 0} \frac{\Delta\vec{v}}{\Delta t} = \vec{v}'(t) = \vec{r}''(t) = (a_x, a_y, a_z)$$
  ### $$a_x = v_x'(t) = x''(t)$$

## 2. Относительность движения и сложение скоростей

### 2.1. Классический закон сложения перемещений и скоростей (преобразования Галилея)
* **Сложение перемещений:**
  ### $$\Delta\vec{r}_{\text{абс}} = \Delta\vec{r}_{\text{отн}} + \Delta\vec{r}_{\text{пер}}$$
* **Сложение скоростей:**
  ### $$\vec{v}_{\text{абс}} = \vec{v}_{\text{отн}} + \vec{v}_{\text{пер}}$$
  * $\vec{v}_{\text{абс}}$ — скорость тела относительно неподвижной системы отсчета (К);
  * $\vec{v}_{\text{отн}}$ — скорость тела относительно подвижной системы отсчета (К');
  * $\vec{v}_{\text{пер}}$ — переносная скорость подвижной системы отсчета относительно неподвижной.
* **Относительная скорость двух тел:**
  ### $$\vec{v}_{12} = \vec{v}_1 - \vec{v}_2$$
* **Условия применимости:**
  * Нерелятивистские скорости ($v \ll c$, где $c = 3 \cdot 10^8\text{ м/с}$).
  * Классическое евклидово пространство (время течет одинаково во всех системах отсчета: $\Delta t = \text{inv}$).

## 3. Равномерное прямолинейное движение (РПД)

### 3.1. Уравнения кинематики
* **Условие движения:** $\vec{a} = 0$, $\vec{v} = \text{const}$.
* **Проекция скорости:**
  ### $$v_x(t) = v_{0x} = \text{const}$$
* **Закон движения (уравнение координаты):**
  ### $$x(t) = x_0 + v_x t$$
* **Проекция перемещения:**
  ### $$s_x = \Delta x = v_x t$$
* **Графический смысл:** проекция перемещения $s_x$ численно равна площади под графиком зависимости $v_x(t)$ на интервале времени от $0$ до $t$.

### 3.2. Средняя путевая скорость
### $$v_{\text{ср}} = \frac{s_{\text{общ}}}{t_{\text{общ}}} = \frac{s_1 + s_2 + \dots + s_n}{t_1 + t_2 + \dots + t_n}$$
* **Частные случаи:**
  * При равенстве интервалов времени ($t_1 = t_2$):
    ### $$v_{\text{ср}} = \frac{v_1 + v_2}{2}$$
  * При равенстве пройденных путей ($s_1 = s_2$):
    ### $$v_{\text{ср}} = \frac{2v_1 v_2}{v_1 + v_2}$$
* **Условия применимости:** $v_{\text{ср}}$ рассчитывается строго через суммарный путь и суммарное время (включая остановки). Формула среднего арифметического неприменима при неравенстве промежутков времени.

## 4. Равноускоренное прямолинейное движение (РУПД)

### 4.1. Уравнения кинематики
* **Условие движения:** $\vec{a} = \text{const}$, траектория — прямая линия.
* **Проекция скорости:**
  ### $$v_x(t) = v_{0x} + a_x t$$
* **Закон движения (координата):**
  ### $$x(t) = x_0 + v_{0x}t + \frac{a_x t^2}{2}$$
* **Проекция перемещения:**
  ### $$s_x(t) = v_{0x}t + \frac{a_x t^2}{2}$$
* **Формула перемещения без времени:**
  ### $$v_x^2 - v_{0x}^2 = 2 a_x s_x \iff v_{2x}^2 - v_{1x}^2 = 2 a_x (x_2 - x_1)$$
  ### $$S_x = \frac{v_x^2 - v_0^2}{2a_x}$$
* **Перемещение через среднюю скорость:**
  ### $$s_x = \frac{v_{0x} + v_x}{2} \cdot t$$
  *Применимо для вычисления пути $s$ строго при условии сохранения знака проекции скорости на всем отрезке времени (без смены направления движения).*

### 4.2. Частные кинематические соотношения
* **Полная остановка ($v_x = 0$):**
  ### $$t_{\text{ост}} = \frac{v_0}{a}, \quad s_{\text{торм}} = \frac{v_0^2}{2a}$$
* **Правило нечетных чисел Галилея (при $v_0 = 0$):**
  ### $$s_1 : s_2 : s_3 : \dots : s_n = 1 : 3 : 5 : \dots : (2n - 1)$$
  *Путь за $n$-ю последовательную равную единицу времени $\Delta t$:*
  ### $$s_n = \frac{a (\Delta t)^2}{2} (2n - 1)$$
* **Условия применимости всех формул РУПД:** строго постоянный вектор ускорения ($\vec{a} = \text{const}$). При наличии точек разворота ($v_x = 0$) путь рассчитывается раздельно по участкам монотонного движения.

## 5. Свободное падение и движение в поле тяжести

### 5.1. Одномерное вертикальное движение
* **Условие свободного падения:** движение происходит исключительно под действием силы тяжести; ускорение тела $\vec{a} = \vec{g} = \text{const}$ ($g = 10\text{ м/с}^2$). Сопротивление среды отсутствует.
* **Падение без начальной скорости ($v_0 = 0$, ось $Oy$ направлена вниз):**
  ### $$v(t) = gt, \quad h(t) = \frac{gt^2}{2}, \quad v = \sqrt{2gh}, \quad t_{\text{пад}} = \sqrt{\frac{2h}{g}}$$
* **Бросок вертикально вверх ($v_{0y} = v_0$, ось $Oy$ направлена вверх):**
  ### $$v_y(t) = v_0 - gt, \quad y(t) = v_0 t - \frac{gt^2}{2}$$
  ### $$t_{\text{под}} = \frac{v_0}{g}, \quad h_{\max} = \frac{v_0^2}{2g}, \quad t_{\text{полн}} = \frac{2v_0}{g}$$

### 5.2. Движение тела, брошенного под углом $\alpha$ к горизонту
Движение представляет собой суперпозицию двух независимых движений: равномерного по горизонтали и равнопеременного по вертикали.
* **Уравнения проекций скорости:**
  ### $$v_x(t) = v_{0x} = v_0 \cos\alpha = \text{const}$$
  ### $$v_y(t) = v_{0y} - gt = v_0 \sin\alpha - gt$$
* **Закон движения (координаты):**
  ### $$x(t) = (v_0 \cos\alpha) t$$
  ### $$y(t) = (v_0 \sin\alpha) t - \frac{gt^2}{2}$$
* **Модуль скорости в любой точке траектории:**
  ### $$v(t) = \sqrt{v_x^2(t) + v_y^2(t)}$$
* **Параметры симметричной траектории (старт и приземление на одной высоте):**
  * Время подъема:
    ### $$t_{\text{под}} = \frac{v_0 \sin\alpha}{g}$$
  * Максимальная высота подъема:
    ### $$h_{\max} = \frac{v_0^2 \sin^2\alpha}{2g}$$
  * Полное время полета:
    ### $$t_{\text{полн}} = \frac{2v_0 \sin\alpha}{g} = 2t_{\text{под}}$$
  * Дальность полета:
    ### $$L = \frac{v_0^2 \sin 2\alpha}{g}$$
    *Максимальная дальность при заданной $v_0$ достигается при угле $\alpha = 45^\circ$.*
* **Уравнение траектории (парабола):**
  ### $$y(x) = (\operatorname{tg}\alpha) x - \frac{g}{2v_0^2 \cos^2\alpha} x^2$$
* **Условия применимости формул баллистики:**
  1. Однородное гравитационное поле ($\vec{g} = \text{const}$).
  2. Размеры тела пренебрежимо малы по сравнению с дальностью и высотой (материальная точка).
  3. Сопротивление воздуха пренебрежимо мало ($F_{\text{сопр}} = 0$).
  4. Формулы для $L$ и $t_{\text{полн}}$ в виде $L = \frac{v_0^2 \sin 2\alpha}{g}$ применимы **только при равенстве начальной и конечной высот** ($y_0 = y_{\text{кон}} = 0$). Для произвольных перепадов высот требуется решение исходных уравнений координат.

## 6. Движение материальной точки по окружности

### 6.1. Кинематические характеристики вращения
* **Период обращения $T$ [с]:** время одного полного оборота:
  ### $$T = \frac{t}{N} = \frac{1}{\nu} = \frac{2\pi}{\omega}$$
* **Частота обращения $\nu$ [Гц, $\text{с}^{-1}$]:** число оборотов за единицу времени:
  ### $$\nu = \frac{N}{t} = \frac{1}{T} = \frac{\omega}{2\pi}$$
* **Угловая скорость $\omega$ [рад/с]:** быстрота изменения угла поворота:
  ### $$\omega = \lim_{\Delta t \to 0} \frac{\Delta\varphi}{\Delta t} = \frac{2\pi}{T} = 2\pi\nu$$
* **Линейная скорость $v$ [м/с]:** скорость движения точки по касательной к траектории:
  ### $$v = \omega R = \frac{2\pi R}{T} = 2\pi\nu R$$

### 6.2. Ускорение при криволинейном движении
Вектор полного ускорения произвольного криволинейного движения:
### $$\vec{a} = \vec{a}_n + \vec{a}_\tau, \quad a = \sqrt{a_n^2 + a_\tau^2}$$
* **Центростремительное (нормальное) ускорение $a_{\text{цс}} = a_n$:**
  Характеризует быстроту изменения **направления** вектора скорости. Направлено по радиусу к центру окружности ($\vec{a}_n \perp \vec{v}$).
  ### $$a_{\text{цс}} = \frac{v^2}{R} = \omega^2 R = \omega v = \frac{4\pi^2 R}{T^2} = 4\pi^2 \nu^2 R$$
* **Тангенциальное (касательное) ускорение $a_\tau$:**
  Характеризует быстроту изменения **модуля** скорости. Направлено по касательной к траектории вдоль линии скорости.
  ### $$a_\tau = v'(t)$$
  * При $v = \text{const}$ (равномерное вращение): $a_\tau = 0 \implies a = a_{\text{цс}}$.

### 6.3. Связи в механических передачах и твердых телах
* **Точки одного твердого тела (вращение вокруг неподвижной оси):**
  ### $$\omega = \text{const} \implies v \sim R, \quad a_{\text{цс}} \sim R$$
* **Ременная, цепная и фрикционная передачи (без проскальзывания):**
  ### $$v = \text{const} \implies \omega \sim \frac{1}{R}, \quad a_{\text{цс}} \sim \frac{1}{R}$$
* **Качение колеса радиуса $R$ без проскальзывания со скоростью оси $v_0$:**
  * Скорость центра: $v_{\text{центр}} = v_0$;
  * Скорость нижней точки (мгновенный центр скоростей): $v_{\text{низ}} = 0$;
  * Скорость верхней точки: $v_{\text{верх}} = 2v_0$.
* **Условия применимости:** радиус кривизны траектории $R = \text{const}$, абсолютно твердое недеформируемое тело или нерастяжимый ремень без проскальзывания.
