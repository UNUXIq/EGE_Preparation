## 1. Физическая модель и условия применимости

> [!info] Свободное падение
> Движение тела под действием исключительно силы тяжести (в безвоздушном пространстве или когда силой сопротивления воздуха можно пренебречь).

* **Ускорение:** является частным случаем равноускоренного прямолинейного движения, при котором ускорение тела строго равно ускорению свободного падения:
  $$\vec{a} = \vec{g} = \text{const}$$
* **Направление вектора $\vec{g}$:** всегда вертикально вниз (к центру Земли).
* **Модуль:** для расчетов в КИМ ЕГЭ принимается $g = 10\text{ м/с}^2$ (в справочных материалах КИМ)
* **Независимость от массы:** в отсутствие сопротивления воздуха все тела любой массы падают с одинаковым ускорением (опыт Галилея / трубка Ньютона).

## 2. Основные случаи одномерного вертикального движения

Ось координат $Oy$ обычно направляют **вертикально вверх** (тогда $g_y = -g$) либо **вертикально вниз** (тогда $g_y = +g$).

### 2.1. Падение без начальной скорости ($v_0 = 0$)
*Выбираем ось $Oy$, направленную вниз от точки броска ($y_0 = 0$):*

* **Уравнение проекции скорости:**
  $$v(t) = gt$$
* **Уравнение координаты (пройденной высоты):**
  $$h(t) = \frac{gt^2}{2}$$
* **Формула без времени:**
  $$v^2 = 2gh \implies v = \sqrt{2gh}$$
* **Время падения с высоты $h$:**
  $$t_{\text{пад}} = \sqrt{\frac{2h}{g}}$$
* **Конечная скорость в момент удара о землю:**
  $$v_{\text{кон}} = \sqrt{2gh}$$

> [!tip] Правило нечетных чисел Галилея
> Так как $v_0 = 0$, за последовательные равные промежутки времени $\Delta t$ тело проходит расстояния, относящиеся как нечетные числа:
> $$h_1 : h_2 : h_3 : \dots = 1 : 3 : 5 : \dots : (2n - 1)$$
> Высота, пройденная за $n$-ю секунду: $h_n = \frac{g}{2}(2n - 1) = 5(2n - 1)\text{ м}$.

---

### 2.2. Бросок вертикально вверх с начальной скоростью $v_0$
*Выбираем ось $Oy$, направленную вверх от поверхности земли ($y_0 = 0$, $v_{0y} = v_0$, $g_y = -g$):*

* **Уравнение проекции скорости:**
  $$v_y(t) = v_0 - gt$$
* **Уравнение координаты (высоты над землей):**
  $$y(t) = v_0 t - \frac{gt^2}{2}$$
* **Формула без времени:**
  $$v_y^2 - v_0^2 = -2gy$$

#### Ключевые точки траектории:
1. **Верхняя точка подъема ($y = h_{\max}$):**
   * В наивысшей точке мгновенная скорость обращается в ноль: $v_y = 0$.
   * **Время подъема:**
     $$0 = v_0 - gt_{\text{под}} \implies t_{\text{под}} = \frac{v_0}{g}$$
   * **Максимальная высота подъема:**
     $$h_{\max} = \frac{v_0^2}{2g} = \frac{v_0 t_{\text{под}}}{2}$$
2. **Возвращение в исходную точку ($y = 0$):**
   * **Симметрия движения:**
     * Время подъема равно времени спуска: $t_{\text{спуск}} = t_{\text{под}} = \frac{v_0}{g}$.
     * Полное время полета:
       $$t_{\text{полн}} = 2 t_{\text{под}} = \frac{2v_0}{g}$$
     * Модуль скорости при приземлении равен начальной скорости: $v_{\text{кон}} = v_0$ (направлен вниз).
   * **Скорость на любой промежуточной высоте $h$:**
     $$v_y = \pm\sqrt{v_0^2 - 2gh}$$
     *(знак «$+$» при движении вверх, знак «$-$» при движении вниз на той же высоте; модули скоростей одинаковы).*

---

### 2.3. Бросок вертикально вниз с начальной скоростью $v_0$
*Выбираем ось $Oy$, направленную вниз ($y_0 = 0$, $v_{0y} = v_0$, $g_y = +g$):*

* **Скорость:**
  $$v(t) = v_0 + gt$$
* **Высота (пройденный путь):**
  $$h(t) = v_0 t + \frac{gt^2}{2}$$
* **Формула без времени:**
  $$v^2 - v_0^2 = 2gh \implies v = \sqrt{v_0^2 + 2gh}$$

## 3. Графический анализ (для броска вертикально вверх)

Если ось $Oy$ направлена вверх:

| График величины | Вид графика | Физический смысл деталей |
| :--- | :--- | :--- |
| **Ускорение $a_y(t)$** | Горизонтальная прямая $a_y = -g = -10\text{ м/с}^2$ | Ускорение не меняется на всем протяжении полета, включая верхнюю точку. |
| **Скорость $v_y(t)$** | Наклонная прямая, идущая вниз ($k = -g$) | • Пересечение с $Oy$: начальная скорость $v_0$.<br>• Пересечение с $Ot$ ($v_y = 0$): момент остановки $t = t_{\text{под}}$.<br>• Ниже оси $Ot$: движение вниз ($v_y < 0$). |
| **Координата $y(t)$** | Парабола, ветви направлены вниз | Вершина параболы соответствует наивысшей точке $(t_{\text{под}},\, h_{\max})$. |
| **Путь $s(t)$** | Параболические участки, график строго возрастает | • До $t_{\text{под}}$: $s(t) = y(t)$.<br>• После $t_{\text{под}}$: $s(t) = h_{\max} + \frac{g(t - t_{\text{под}})^2}{2}$. |

## 4. Свойства относительного движения в поле тяжести

> [!tip] Полезный метод для сложных задач (№ 26)
> Если в поле тяжести одновременно движутся два тела (оба находятся в свободном падении), их относительное ускорение равно нулю:
> $$\vec{a}_{\text{отн}} = \vec{g}_1 - \vec{g}_2 = \vec{g} - \vec{g} = 0$$

* В системе отсчета, связанной с одним из свободно падающих тел, **второе тело движется равномерно и прямолинейно** с относительной скоростью:
  $$\vec{v}_{\text{отн}} = \vec{v}_1 - \vec{v}_2 = \text{const}$$
* Это упрощает нахождение времени до столкновения тел, брошенных навстречу друг другу:
  $$t_{\text{встр}} = \frac{L_0}{v_{\text{сбл}}}$$

## 5. Типовые ловушки и нюансы КИМ ЕГЭ

1. **Ускорение в верхней точке:**
   * В верхней точке подъема скорость тела мгновенно равна нулю ($v = 0$), но **ускорение не равно нулю** — оно по-прежнему равно $\vec{g}$ (сила тяжести продолжает действовать).
2. **Путь vs Координата/Перемещение:**
   * Если тело брошено вверх с высоты $H$ (с балкона или обрыва) и упало на землю:
     * Перемещение: $\Delta y = -H$ (модуль перемещения равен $H$).
     * Пройденный путь: $s = 2h_{\text{под}} + H$, где $h_{\text{под}} = \frac{v_0^2}{2g}$.
3. **Обоснование для задачи № 26 (Критерий К1):**
   При решении задач со свободным падением обязательно фиксируются следующие тезисы:
   > 1. *«Выберем систему отсчета, связанную с Землей, которую считаем инерциальной (ИСО)»*
   > 2. *«Тело описываем моделью материальной точки, так как его размеры пренебрежимо малы по сравнению с высотой подъема и траекторией»*
   > 3. *«Сопротивлением воздуха пренебрегаем, единственной действующей силой является сила тяжести, поэтому движение тела является свободным падением с постоянным ускорением $\vec{a} = \vec{g} = \text{const}$»*
